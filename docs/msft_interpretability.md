# Объяснение прогнозов MSFT

Подробно исследуется Ridge с рыночными признаками и alpha = 1000: это лучший обучаемый вариант по validation. Основным прогнозом остаётся последнее известное закрытие, показавшее меньшую ошибку. Объяснение Ridge не означает, что он лучше базового прогноза. Для базового прогноза правило полностью прозрачно: следующая цена равна предыдущему закрытию.

Модель Ridge и её преобразования зафиксированы после обучения на train+validation, до test. Для всех объяснений используется один и тот же файл модели; его SHA-256 и хеш протокола включены в [отчёт](../reports/msft_interpretability.json). При изучении test параметры заново не подбираются.

## Два метода важности

**Средний абсолютный вклад.** В линейной модели каждый преобразованный признак умножается на свой коэффициент. Из значения признака вычитается его среднее на обучающей части; столбцы one-hot объединяются обратно в исходную категорию. Средний модуль вклада показывает, насколько сильно признак меняет прогноз относительно этого среднего. Результат выражается в USD и базисных пунктах прогнозируемого изменения цены.

На полном test самые большие средние модули вкладов: изменение цены за одну сессию — 0,2956 USD, изменение от открытия до закрытия — 0,2609 USD, доходность с лагом 5 — 0,2607 USD. Большой вклад не означает полезность для точности.

**Блочная перестановочная важность.** Для каждого исходного признака его значения переставляются блоками по 20 последовательных сессий, другие признаки и модель сохраняются. Выполняются 10 повторов с фиксированным seed 42. Изменение MAE относительно исходного порядка измеряется в USD. Положительное значение означает ухудшение после перестановки; отрицательное — улучшение. Внутри блоков сохраняется порядок, но связи между блоками и между признаками нарушаются.

На полном test наибольшее среднее ухудшение MAE даёт перестановка доходности с лагом 5: +0,0438 USD. Далее идут волатильность за 20 сессий (+0,0194) и доходность с лагом 1 (+0,0125). Эти значения описывают зависимость данной модели от входов; они не доказывают устойчивое преимущество признаков на будущих данных. Разброс повторов в JSON — стандартное отклонение по перестановкам, не доверительный интервал.

## Отдельный прогноз

Для любой из 252 тестовых дат доступно точное разложение:

`прогноз = последнее закрытие + средняя поправка Ridge + сумма вкладов признаков`.

Средняя поправка соответствует свободному члену и среднему вектору преобразованных обучающих признаков. Вклады показывают отклонение конкретной строки от этого вектора. Последняя цена используется также для перевода доходности в USD; разложение не приписывает ей причинный эффект.

В дашборде дата выбирается вручную; рядом показаны факт, базовый прогноз, Ridge, время отсечки и последняя известная свеча. Для всех 252 дат сумма воспроизвела прогноз с максимальной погрешностью **1,14 × 10⁻¹³ USD**. Полные объяснения сохраняются локально в `data/processed/msft/local_explanations.json`, пример включён в опубликованный отчёт.

## Зависимость от отдельного признака

PDP доступен для всех 18 числовых рыночных признаков. Один признак изменяется по 25 квантильным точкам между 5-м и 95-м процентилями обучающей части; остальные берутся из фиксированной выборки 100 обучающих строк. Показывается среднее прогнозируемое изменение цены в базисных пунктах: 1 б.п. = 0,01%. Для линейного Ridge графики линейные, что соответствует устройству модели.

## Сравнение периодов

Тестовый год разделён по порядку наблюдений на две равные части. Модель и точка отсчёта вкладов одинаковы, поэтому сравнивается поведение одной модели при изменении входных данных.

| Период | Сессий | MAE базового, USD | MAE Ridge, USD |
|---|---:|---:|---:|
| 15.10.2025–16.04.2026 | 126 | 5,4567 | 5,7247 |
| 17.04.2026–15.10.2026 | 126 | 6,9035 | 7,1043 |

Во второй половине ошибка выше у обеих моделей. Средний модуль вклада однодневной доходности увеличился с 5,83 до 7,61 б.п. Дашборд сопоставляет важности в относительных единицах, чтобы изменение уровня цены не определяло сравнение само по себе. Это описательная проверка, а не формальный тест дрейфа.

## Ограничения и проверка

Коррелирующие рыночные признаки разделяют информацию; их отдельные вклады зависят от выбранной модели. Перестановки и PDP могут создавать нетипичные сочетания. Все результаты относятся к ассоциациям внутри Ridge, а не к причинным эффектам. Тексты не входят в объясняемый вариант: их влияние оценено отдельно в [сравнении моделей](msft_results.md).

Код: `msft_explain.py`; запуск: `.\.venv\Scripts\python.exe scripts/explain_msft.py`. Автоматические проверки подтверждают точность суммы на новых строках, обнаружение известного сигнала перестановкой, воспроизводимость, сохранение всех наблюдений при перестановке и правильный наклон PDP для искусственной линейной зависимости.
