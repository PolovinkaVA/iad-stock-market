# Исходный прототип SBER

Сохранён первым коммитом `ad9627b`. Это предшествующий прототип, а не реализация текущей постановки MSFT. Готовность к защите не подтверждена. Историческую схему см. в [первоначальном описании](project_spec.md).

## Состав и стек

В `src/stocks_forecast/` есть загрузчик MOEX ISS и RSS Банка России (`ingest.py`), подготовка признаков (`prepare.py`), сравнение моделей (`modeling.py`), анализ признаков (`feature_analysis.py`) и интерфейс (`dashboard.py`).

Используются Python, SQLite, scikit-learn, Streamlit/Plotly и YAML. SQLite позволяет хранить данные без отдельного сервера, scikit-learn предоставляет модели, Streamlit — учебный интерфейс. Подходящие компоненты предполагается сохранить при переходе на MSFT.

## Результаты и ограничения

В `reports/model_comparison.json` сохранён выбор линейной регрессии с пятью ценовыми признаками: MAE на валидации около 3,29 руб., на тесте около 2,43 руб. Это результаты прежнего запуска, не повторное подтверждение в ходе текущего аудита и не показатели MSFT.

RSS дал 15 публикаций, покрывающих 11 из 2 180 строк (около 0,50%). Текстовые признаки исключены из обучения. Порог покрытия 20% не является требованием методички.

Расчёт исторических и текущих признаков продублирован; нужен единый код. Отсутствие утечки требует проверки временной доступности признаков. `reports/monitoring.json` описывает историческую ошибку, а не полный компонент мониторинга с переобучением, версиями и откатом.

## Запуск из корня проекта

```powershell
python -m pip install -r requirements.txt
$env:PYTHONPATH = "src"
python -m stocks_forecast.ingest
python -m stocks_forecast.prepare
python -m stocks_forecast.modeling
python -m stocks_forecast.feature_analysis
python -m streamlit run src/stocks_forecast/dashboard.py
```

Четыре этапа до интерфейса также перечислены в `run_pipeline.ps1`; конфигурация — `config/config.yaml`. Запуск скачивает данные и пересчитывает локальные артефакты, включая прежние результаты.

Полный запуск из чистого окружения остаётся отдельной проверкой. На 15 октября подтверждена воспроизводимость аудитора Microsoft, а не всего SBER-конвейера. Данные, модели и предварительные офисные документы сохраняются локально.
