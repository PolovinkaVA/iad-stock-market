# Фондовый рынок — семестровый проект по ИАД

Учебный проект магистратуры НИТУ МИСИС по дисциплине «Интеллектуальный анализ данных». Цель — разработать прогнозно-аналитическую систему с автоматическим сбором данных, подготовкой признаков, сравнением моделей и интерактивным дашбордом.

## Состояние на 16 октября 2026 года

**Согласованная постановка: Microsoft (MSFT), прогноз цены закрытия следующего торгового дня.** Объём используется как признак. Достаточно полностью реализовать дополнительное направление «Интерпретируемость моделей». По ответам преподавателя, переданным студентом 16 октября, текущие тексты пресс-релизов разрешено использовать с описанием ограничения; искать первоначальные версии не требуется. Отсутствие улучшения от текстов допустимо как результат исследования.

| Часть проекта | Подтверждённое состояние |
|---|---|
| Источники MSFT | Проверены котировки Yahoo Finance и официальный архив пресс-релизов Microsoft |
| Котировки | 2 207 дневных записей за 02.01.2018–13.10.2026; базовые проверки OHLCV пройдены |
| Тексты | Скачаны 526 публикаций выбранного периода; последовательно просмотрены 45 страниц архива |
| Воспроизводимость аудита | Повтор из локального кэша дал те же результаты и хеш манифеста; четыре проверки парсинга прошли |
| Исторические версии текстов | Не подтверждены: у 471 страницы дата изменения позже публикации более чем на сутки |
| Модели и дашборд MSFT | Ещё не реализованы |
| Исходный прототип SBER | Сохранён в истории Git; его код находится в `src/stocks_forecast/` |

Проверка источников выполнена 14 октября. Эти результаты не означают, что тексты уже пригодны для строгой исторической проверки прогноза или что все требования методички закрыты. Качество прогнозов MSFT пока не оценивалось.

## Запуск проверки Microsoft

Команды выполняются из корня проекта. Для аудитора нужен Python 3.10+; дополнительных Python-пакетов он не требует.

```powershell
python scripts/audit_microsoft.py --end 2026-10-13
python -m unittest discover -s tests -v
```

Первый запуск скачивает данные из внешних источников и может занять несколько минут. Он создаёт локальный кэш в `tmp/us_sources/audit_cache/` и отчёты:

- [Сводка проверок](reports/microsoft_audit.json).
- [Манифест публикаций: URL, даты, длины и хеши](reports/microsoft_articles.csv).

Повторная проверка **на компьютере, где уже есть кэш**:

```powershell
python scripts/audit_microsoft.py --end 2026-10-13 --offline --report tmp/us_sources/offline_audit.json
```

Сырые тексты и котировки не включены в Git. На новом компьютере сначала нужен сетевой запуск. Источники могут менять страницы, поэтому новая загрузка не обязана совпадать со снимком от 14 октября. Сохранённые хеши позволяют сравнить результаты. Аудитор использует кэш; это ещё не производственный загрузчик с регулярным обновлением всех данных.

## Следующие этапы

1. Реализовать согласованный протокол: текущие тексты привязываются к дате публикации с явным допущением об историческом содержимом; сохраняются версии и обе даты.
2. Проверить календарь торгов и корпоративные действия.
3. Реализовать загрузку MSFT, хранение версий, журнал запусков и проверки качества.
4. Создать единый расчёт признаков для обучения и рабочего прогноза; проверить отсутствие утечки будущих данных.
5. Сравнить baseline и модели разных классов по временной схеме, оценить влияние текстовых признаков.
6. Реализовать интерпретируемость, дашборд, затем подготовить итоговые отчёт и презентацию.

Критерии завершения определяются [картой требований методички](docs/requirements_matrix.md), а не наличием файлов отчёта или презентации.

## Структура репозитория

```text
docs/                       постановка, архитектура, требования, журнал
scripts/audit_microsoft.py   аудит архива Microsoft и котировок MSFT
scripts/probe_us_sources.py  предварительная выборочная проверка источников
tests/                      проверки парсинга и временных меток
reports/microsoft_*         результаты расширенного аудита MSFT
src/stocks_forecast/         исходный прототип SBER
config/config.yaml          конфигурация исходного прототипа SBER
reports/model_comparison.*  сохранённые результаты SBER
tmp/                        локальные загрузки и кэш (не публикуются)
data/, models/              локальные данные и модели SBER (не публикуются)
```
